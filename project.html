캡스톤 프로젝트

실시간 수어 번역 모바일 앱

Sign Language Real-Time Translation App

형태
3~4인 팀 프로젝트
역할
백엔드 & 데이터베이스
상태
개발 중

청각 장애인의 의사소통 장벽 해소를 목표로 개발한 Android 기반 실시간 수어 번역 앱입니다. 카메라로 수어 동작을 인식하고, 텍스트와 음성으로 실시간 변환하는 기능을 구현하고 있습니다.

  1. 앱카메라로 수어 동작 입력
  2. RESTful API클라이언트-서버 통신
  3. 서버수어 인식 결과 처리
  4. DB인식 데이터·사용자 정보 저장

담당 역할

백엔드 서버 설계 & 구현
클라이언트(앱)와의 데이터 통신을 위한 RESTful API를 설계하고 개발했습니다. 수어 인식 결과를 처리하는 로직을 구현했습니다.
데이터베이스 설계
수어 인식 데이터와 사용자 정보를 저장하는 DB 스키마를 설계하고, 데이터 무결성과 성능을 최적화했습니다.
실시간 데이터 처리 최적화
번역 결과의 지연을 최소화하도록 서버 로직 구조를 설계하고, 클라이언트-서버 간 데이터 흐름을 최적화했습니다.
기술 자기주도 학습 & 트러블슈팅
실시간 번역 요구사항을 구현하려고 기술 문서를 스스로 탐독해 팀에 적용하고, 문제 해결을 주도했습니다.

사용 기술

  • RESTful API

  • 실시간 데이터 처리
