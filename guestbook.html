    이 방명록의 보안 설계

    누구나 글을 쓸 수 있는 공간은 공격받기도 쉽습니다. 데이터 보안을 공부하는 입장에서 아래처럼 설계했습니다.

    DB 접근 권한 (Row Level Security)
    방문자에게는 글 읽기와 쓰기 권한만 줍니다. 수정 · 삭제 정책을 아예 만들지 않아, 남의 글은 물론 내 글도 바꿀 수 없습니다. 관리는 관리자 화면에서만 합니다.
    입력값 검증 (앱 + DB 두 겹)
    이름 20자, 내용 300자 제한을 화면에서 먼저 검사하고, DB 제약 조건으로 한 번 더 막습니다. 화면 검사를 우회해도 DB가 거부합니다.
    XSS 방어
    글을 화면에 그릴 때 HTML로 해석하지 않고 순수한 글자로만 넣습니다. 내용에 스크립트를 넣어도 실행되지 않고 글자 그대로 보입니다.
    도배 · 봇 방지
    같은 브라우저에서는 30초에 한 번만 쓸 수 있고, DB는 1분에 전체 10건이 넘으면 저장을 거부합니다. 사람에게 보이지 않는 칸을 채우는 자동 글쓰기 봇은 걸러 냅니다.
    공개 키와 권한 분리
    페이지에 들어 있는 키는 공개용(anon) 키라 노출돼도 위 권한 밖의 일은 할 수 없습니다. 관리자 키는 사이트 어디에도 넣지 않았습니다. Smart Fridge에서 배운 "키는 서버에, 권한은 정책으로" 원칙을 그대로 적용했습니다.
