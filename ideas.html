앞으로 추가할 아이디어

계획 단계 아직 포트폴리오에 반영하지 않은 내용이고, 아래 방향으로 확장할 계획입니다.

앞으로는 인프라·DB 암호화 실무 경력과 클라우드 보안 공부를 앞세우고, 캡스톤(Smart Fridge)은 프로젝트 중 하나로 정리하려고 합니다.

1. 추가할 경력

  • 블루어드 — 인프라솔루션 팀 경력 사항 추가, 블루어드 로고 삽입. SAP DB의 이름·주소·주민등록번호 등 개인정보 컬럼을 암호화한 프로젝트 경험을 정리 2026.07.20 ~ 2026.09.01
  • GBA PARTNERS — 통합개발팀 주니어 개발자 경력 사항 추가, GBA 사진 삽입 2026.01 ~ 2026.06

2. 내용의 방향 바꾸기

캡스톤 이야기보다 위 경력(인프라, DB 암호화) 쪽 비중을 키웁니다. 소개글, 기술 스택, 커리어 목표도 이 방향에 맞게 다시 씁니다.

3. 프로젝트와 공부 내용 추가

직접 만들어 본 프로젝트
지금까지 만든 프로젝트를 정리해서 프로젝트 페이지에 추가합니다.
AWS 클라우드 보안 자격증 준비 중
준비하고 있다는 내용과 학습 순서(AWS 클라우드 기초 → CPPG → CCSP)를 커리어 페이지에 넣습니다. 자격증 이름과 시험 예정일은 확정되면 적습니다.
Smart Fridge 시연 영상
영상과 화면 캡처를 프로젝트 페이지에 넣습니다. 지금 바로 넣지는 않고 나중에 추가합니다.

4. 색상 테마 비교

이전 테마
진한 청록 남색 배너와 민트 포인트. 색상 값은 mportfolio.css 상단 주석에 남겨 두었습니다.
적용한 테마: 화이트 + 블루 적용
흰 배경에 파란색 포인트. 배경 #FFFFFF, 연한 면 #F4F8FF, 글자 #0F1B33, 메인 블루 #2563EB, 진한 블루 #1D4ED8.

진행 순서

  1. 1단계

    화이트·블루 테마 비교 후 선택

    두 테마를 나란히 보고 하나로 정합니다.

  2. 2단계

    경력 페이지 추가

    블루어드(인프라솔루션 팀, DB 암호화)와 GBA PARTNERS(통합개발팀, 주니어 개발자) 경력에 로고와 사진을 넣습니다.

  3. 3단계

    프로젝트와 자격증 준비 내용 정리

    만들어 본 프로젝트와 AWS 클라우드 보안 자격증 준비 내용을 넣고, 소개글의 방향을 바꿉니다.

  4. 4단계

    Smart Fridge 시연 영상 추가

    영상과 화면 캡처를 넣어 프로젝트 페이지를 마무리합니다.

확정 전에 확인할 것
