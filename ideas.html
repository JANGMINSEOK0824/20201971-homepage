포트폴리오 개선 현황

진행 중 인프라 · DB 암호화 실무 경력과 클라우드 보안 공부를 앞세우는 방향으로 포트폴리오를 다시 정리하고 있습니다. 처음 세운 계획은 대부분 반영했고, 아래에 남은 일을 정리했습니다.

완료한 작업

  • 경력 추가 블루어드(인프라솔루션 팀 인턴, SAP HANA DB 암호화)와 GBA PARTNERS(통합개발팀, SAP SD 개발) 경력을 커리어 페이지에 정리. 로고는 사용 허락 전까지 글자 배지로 대체 완료
  • 방향 전환 직함을 Infra & Data Security Engineer로 바꾸고, 소개글과 기술 스택에 인프라 · 보안 경험 추가 완료
  • 캡스톤 프로젝트 정리 Smart Fridge의 구조, 담당 역할, 문제 해결 과정을 프로젝트 페이지에 정리 완료
  • 자격증 준비 내용 AWS Cloud Practitioner 응시 예정(2026.11)과 학습 순서(AWS 기초 → CPPG → CCSP)를 커리어 페이지에 추가 완료
  • 색상 테마 청록 → 화이트 · 블루 → 미드나이트 사파이어(네이비 · 사파이어 · 골드)로 정착. 라이트 · 다크 전환 버튼 추가 완료
  • 인터랙션 야경 도시 잠금 화면, 배너 빛줄기 모션, 기술 칩 설명, 스크롤 등장 효과, 학교 위치 지도 완료
