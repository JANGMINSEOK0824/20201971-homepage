자기소개

장안대학교 컴퓨터공학과에 재학 중인 주니어 AI 개발자입니다. 캡스톤 프로젝트 Smart Fridge(AI 냉장고 관리 · 맞춤 레시피 추천)에서 백엔드 · DB · AI 연동을 맡아 REST API 14개와 공공데이터 1,156건 기반 추천 로직을 구현했습니다.

GBA PARTNERS 통합개발팀에서 SAP SD 개발을 맡았고, 블루어드 인프라솔루션 팀 인턴으로 SAP HANA 개인정보 암호화 솔루션 구축과 성능 테스트를 경험하며 데이터 보안으로 관심을 넓혔습니다.

표준화된 데이터 위에 AI를 얹어, 설비가 스스로 판단하고 움직이는 자율형 시스템을 만드는 개발자로 성장하는 것이 목표입니다.

모든 가치의 중심은 DATA이고, 그 데이터를 학습해 스스로 판단하는 AI가 핵심이라고 생각합니다.
